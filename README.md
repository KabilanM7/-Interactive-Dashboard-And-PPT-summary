 Superstore Sales Analysis Dashboard

 Project Overview
This project focuses on analysing Superstore sales data and creating an interactive dashboard using Microsoft Power BI.

 Dataset
- Dataset: Superstore.xlsx
- Total Records: 9,994
- Total Columns: 21
- Date Range: 2011–2014

 Tools Used
- Microsoft Power BI
- Microsoft Excel
- DAX

 Key KPIs
- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Profit Margin
- Sales Growth

 Dashboard Features
- Sales and profit trend analysis
- Sales by category and region
- Profit by sub-category
- Customer segment analysis
- Interactive slicers and filters

 Key Findings
- Technology generated the highest sales and profit.
- West region recorded the highest sales.
- Tables recorded a negative total profit.
- Sales increased by approximately 20.62% in 2014 compared with 2013.

Deliverables
- Interactive Power BI Dashboard
- PowerPoint Summary
- Dashboard Screenshot

## Conclusion
The dashboard helps business stakeholders understand sales performance, identify profitable categories, and find areas that require improvement.
